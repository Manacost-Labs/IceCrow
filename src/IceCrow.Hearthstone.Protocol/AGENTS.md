# Protocol boundary

Treat every line as untrusted. Parsing returns an explicit parsed, ignored,
malformed, or unknown result; ordinary unknown syntax must not throw. Keep
patterns centralized and bounded, never assume a regex matched, and maintain
only parser context such as the block stack. Do not reference entity state,
Battlegrounds, WPF, files, or network services. Add fixture-driven event-object
tests for every supported or malformed shape.
